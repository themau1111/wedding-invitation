# Project overview

The original portfolio invitation is a Next.js 15 / React 19 frontend. It includes public invitation content, an RSVP-related Supabase client, and dedicated login/admin routes. It is a reference for functionality, not a direct template for the second invitation.

The paired original server implementation is `../wedding-backend`, reached only through its configured HTTPS URL. The new projects are separate portfolio products and have no runtime dependency on this application; see `docs/architecture.md`.
